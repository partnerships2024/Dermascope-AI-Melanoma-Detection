# Notebooks Directory

This directory contains Jupyter notebooks for exploratory data analysis (EDA), prototyping, and visualization.

Recommended notebooks:
1. `01_EDA.ipynb`: Data exploration and distribution analysis.
2. `02_Preprocessing.ipynb`: Visualizing the effect of DullRazor hair removal and segmentation.
3. `03_GradCAM_Analysis.ipynb`: Step-by-step interpretability analysis using Grad-CAM.
